# Allowed growth-parameter names for `linkages` in [`build_growth()`](https://grantdadams.github.io/Rceattle/reference/build_growth.md)

Linear-predictor names of the underlying growth-function parameters. Von
Bertalanffy uses `log_K`, `log_L1`, `log_Linf`; Richards adds `log_m`.
The empirical weight-at-age model admits no linkages.

## Usage

``` r
GROWTH_LINKAGE_PARAMS
```

## Format

An object of class `character` of length 4.
