# Combine two Rceattle data lists

Concatenate two data lists into one. `env_data` is taken from
`data_list1`, and diet data must be updated afterward.

## Usage

``` r
combine_data(data_list1 = NULL, data_list2 = NULL)
```

## Arguments

- data_list1:

  Rceattle data_list 1

- data_list2:

  Rceattle data_list 2
