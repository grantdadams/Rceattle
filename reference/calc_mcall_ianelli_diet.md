# Function to calculate McAllister-Ianelli weights for diet data

Function to calculate McAllister-Ianelli weights for diet data

## Usage

``` r
calc_mcall_ianelli_diet(data_list = NULL, quantities = NULL)
```

## Arguments

- data_list:

  an Rceattle data_list

- quantities:

  list of "report" objects from Rceattle, including diet_hat predictions
