# Function to calculate McAllister-Ianelli weights

Function to calculate McAllister-Ianelli weights

## Usage

``` r
calc_mcall_ianelli(
  data_list = NULL,
  data_list_reorganized = NULL,
  quantities = NULL
)
```

## Arguments

- data_list:

  an Rceattle data_list

- data_list_reorganized:

  reorganized data_list

- quantities:

  list of "report" objects from Rceattle.
