# Pearson residual for an observed proportion

\\(p - \hat p)/\sqrt{\hat p (1 - \hat p)/N}\\ – the multinomial-bin
Pearson residual shared by the composition, conditional-age-at-length,
and diet branches of
[`residuals.Rceattle()`](https://grantdadams.github.io/Rceattle/reference/residuals.Rceattle.md).

## Usage

``` r
.pearson_proportion(observed, fitted, n)
```

## Arguments

- observed, fitted:

  Observed and fitted proportions.

- n:

  Input sample size.
