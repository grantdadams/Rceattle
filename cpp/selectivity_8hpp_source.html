5 * @brief Zeroes, normalizes and projects ONE fleet's selectivity (age or length based).
6 *
7 * @details Bins below bin_first_selected are zeroed; the last hindcast year carries
8 * across the projection. Normalization runs only when Sel_norm_bin is set (default Off),
9 * never for forms 5, 11 and 15: scaling to 1 at sel_norm_bin1, to a mean of 1 over
10 * [bin1, bin2], or to the maximum when bin1 is negative. Under Sel_norm_scope =
11 * AcrossSexes the less-selected sex deliberately peaks below 1.
12 *
13 * @param flt Fleet index.
14 * @param nyrs_hind Years in the hindcast.
15 * @param nyrs Years, hindcast plus projection.
16 * @param flt_spp Fleet index to species index.
17 * @param flt_sel_type Selectivity form per fleet.
18 * @param flt_sel_dim Age (0) or length (1) based selectivity.
19 * @param bin_first_selected First selected age/length bin per fleet, 0-based.
20 * @param nages Age bins per species.
21 * @param nlengths_pop Population length bins per species.
22 * @param nsex Sexes modelled per species: 1 = combined, 2 = both.
23 * @param sel_norm_bin1 Normalization bin, or a control flag when negative.
24 * @param sel_norm_bin2 Upper bin for mean-over-range normalization.
25 * @param sel_norm_scope Per fleet: 0 = WithinSex (each sex divided by its own reference,
26 * so both reach 1), 1 = AcrossSexes (one pooled reference, so the less-selected sex
27 * stays below 1). Orthogonal to sel_norm_bin1/2, which say WHERE it is taken.
28 * @param selectivity 4D (fleet, sex, age or length bin, year), modified in place.
29 */

166/**
167 * @brief Calculates selectivity for every fleet, sex, bin (age or length) and year.
168 *
169 * @details Builds each fleet's hindcast curve from its Selectivity form, applies the
170 * per-sex apical height, then normalizes and projects via
171 * `normalize_and_project_selectivity()`; `convert_length_selectivity()` carries a
172 * length-based curve to ages. `flt_sel_dim` (0 = age, 1 = length) picks the grid per
173 * case, so a length-based curve has no case of its own.
174 *
175 * @section functional_forms Selectivity forms
176 * The codes are fleet_control$Selectivity; R/0-switches.R is the authority. The
177 * parametric forms (1, 3, 4, 8, 11, 15) take linkage offsets in the slots named at their
178 * case; 15 has no deviate array and varies only through linkages. The coefficient forms
179 * (2, 5, 6, 7, 9, 13) take annual deviates but no linkage offset -- build_selectivity()
180 * refuses one, since mean-centring cancels a per-year offset. x below is the length-bin
181 * midpoint (cm) or, on an age-based fleet, the 1-based age-bin ordinal bin + 1
182 * (LogisticPM uses bin + 1.5); minage is NOT added, so an inflection or peak is on the
183 * bin scale, not the age scale.
184 *
185 * - 0 Fixed: read from emp_sel_obs; age-based.
186 * - 1 Logistic: ascending logistic on log_sel_slp(0) and sel_inf(0).
187 * - 2 NonParametric (Ianelli et al. 2018, AMAK): one log-scale coefficient per bin,
188 * sel_coff bins 0..N_sel_bins-1 with the rest plateauing, mean-centred, and penalized
189 * for monotonicity and curvature.
190 * - 3 DoubleLogistic (Dorn and Methot 1990): ascending logistic x (1 - descending).
191 * - 4 DescendingLogistic: the descending limb alone, on log_sel_slp(1)/sel_inf(1).
192 * - 5 Hake (Taylor et al. 2014): cumulative sum of sel_coff from bin_first_selected up,
193 * exponentiated and normalized per sex to 1 at one sel_norm_bin1, else at its
194 * maximum.
195 * - 6 2DAR1: inverse-logit of sel_coff + sel_coff_dev, the deviates carrying an AR1
196 * correlation across bin and year.
197 * - 7 3DAR1 (Cheng et al 2024): conditional-variance parameterisation of a 3D random
198 * field across age, cohort and year.
199 * - 8 DoubleNormal: four-parameter dome, Gaussian limbs blended by a steep logistic so
200 * the curve is twice differentiable, with a logit-scale right-tail floor analogous to
201 * SS3 pattern 24's P6.
202 * - 9 NonParametricPM (AMAK "pm"): random walk on the per-year-centred log-selectivity,
203 * held flat above flt_sel_cap_bin; its increments are penalized, not integrated, so
204 * it is not integrable under random_sel.
205 * - 11 LogisticPM (ADMB AMAK "pm" bottom-trawl survey): logistic with MULTIPLICATIVE
206 * slope and inflection deviates, plus a free first-bin log-selectivity.
207 * - 13 NonParametricIntegrable: the NonParametric curve whose deviates carry a proper
208 * density, so random_sel can integrate them; Time_varying_sel picks Off, IID or
209 * RandomWalk.
210 * - 15 DoubleNormalSS3: Stock Synthesis size pattern 24 (age pattern 20) on SS3's own six
211 * parameters -- P1 peak (cm or age), P2 top width (logit), P3/P4 ascending and
212 * descending widths (log), P5/P6 initial and final selectivity (logit) -- held in
213 * their own array sel_dn6. Unnormalized: the curve peaks at 1 by construction.
214 *
215 * @param nspp Number of species.
216 * @param n_flt Number of fleets.
217 * @param nyrs Years, hindcast plus projection.
218 * @param nyrs_hind Years in the hindcast.
219 * @param styr Start year (for indexing empirical data).
220 * @param nsex Sexes modelled per species: 1 = combined, 2 = both.
221 * @param nages Age bins per species.
222 * @param nlengths Observation length bins per species.
223 * @param lengths Data length bins per species; only the first is read, to locate SS3's
224 * startbin for DoubleNormalSS3.
225 * @param flt_spp,flt_sel_type,flt_sel_dim,bin_first_selected,sel_norm_bin1,sel_norm_bin2
226 * Per fleet, as in normalize_and_project_selectivity() above.
227 * @param flt_n_sel_bins Bins with estimated coefficients per fleet (N_sel_bins).
228 * @param emp_sel_obs Empirical selectivity-at-age observations, one row per record.
229 * @param emp_sel_ctl Fleet, species, sex and year index for each emp_sel_obs row.
230 * @param log_sel_slp Log-scale logistic slope, two slots per fleet and sex.
231 * @param log_sel_slp_dev Annual slope deviations.
232 * @param sel_inf Inflection bin, two slots per fleet and sex.
233 * @param sel_inf_dev Annual inflection deviations.
234 * @param sel_coff Per-bin coefficients for the non-parametric and AR1 forms.
235 * @param sel_coff_dev Annual coefficient deviations.
236 * @param avg_sel [Output] Log mean selectivity over the estimated bins, per
237 * fleet/sex/year. Written by forms 2 and 13 only; forms 5 and 9 leave it at 0.
238 * @param non_par_sel [Output] Non-parametric selectivity on the natural scale.
239 * @param log_non_par_sel [Output] The same curve on the log scale, the scale the
240 * non-parametric selectivity penalties are written on.
241 * @param sel_at_length,sel_at_age [Output] Final length- and age-based selectivity.
242 * @param growth_matrix Length-at-age probability transition matrix.
243 */

330 for (int flt = 0; flt < n_flt; flt++) {

332 int sel_type = flt_sel_type(flt);
333 if (sel_type == 0) continue;

335 // NonParametricIntegrable (13) builds its curve two ways -- a random walk on the
336 // base coefficients under Time_varying_sel = "RandomWalk" (4), otherwise the shared
337 // non-parametric branch -- so the switch dispatches on both columns. The negative
338 // case label is internal; it is not a Selectivity value.
339 const int SEL_CASE_NP_INTEGRABLE_WALK = -13;
340 int sel_case = (sel_type == 13 && flt_varying_sel(flt) == 4)
341 ? SEL_CASE_NP_INTEGRABLE_WALK : sel_type;

344 // A length-based curve runs over the POPULATION bins, an age-based one over ages.
345 int nbins = is_length_based? nlengths_pop(sp) : nages(sp);
346 int n_sel_bins = flt_n_sel_bins(flt);
347 // Bin midpoints, SS3's len_bins_m. A population length grid need not be uniform --
348 // SS3 models routinely widen the tail bins -- so each bin takes its OWN width,
349 // keeping the curve on the same midpoints as the age-length key it multiplies.
350 // A single length bin has no neighbour to take a width from, so it keeps its edge.
351 vector<Type> xmid(nbins);

355 } else if (nbins < 2) {
356 xmid(b) = lengths_pop(sp, b);
357 } else {

359 : (lengths_pop(sp, b) - lengths_pop(sp, b - 1));
360 xmid(b) = lengths_pop(sp, b) + 0.5 * w;
361 }
362 }

364 // where the grid is not uniform (SS_readdata_330.tpl:1644). Read only by the
365 // DoubleNormalSS3 peak2, as SS_selex.tpl:153 does.
366 Type binwidth = (is_length_based && nbins > 1)
367 ? (lengths_pop(sp, nbins / 2) - lengths_pop(sp, nbins / 2 - 1)) : Type(1.0);

370 // and NonParametricIntegrable (13) random walks.
371 array<Type> np_unc(nsex(sp), nbins, nyrs_hind); np_unc.setZero();
372
373 for (int yr = 0; yr < nyrs_hind; yr++) {
374 for (int sex = 0; sex < nsex(sp); sex++) {
375

377 case 1: // Logistic
378 for (int bin = 0; bin < nbins; bin++) {
379 Type x_val = is_length_based ? xmid(bin) : Type(bin + 1);
380 // Linkage convention for all forms below: a log-scale parameter takes its
381 // log-link offset inside the exp, its natural offset after; a natural-scale
382 // one takes the identity offset additively, the log one multiplicatively.
383 Type slope = exp(log_sel_slp(0, flt, sex) + log_sel_slp_dev(0, flt, sex, yr)
384 + sel_slp_off(0, flt, sex, yr)) + sel_slp_off_nat(0, flt, sex, yr);

386 + sel_inf_off_nat(0, flt, sex, yr)) * exp(sel_inf_off(0, flt, sex, yr));

390 else sel_at_age(flt, sex, bin, yr) = val;
391 }

395 // curve on the base coefficients plus the running sum of increments (years after
396 // the fleet's start year). Only the realized curve is mean-centred -- the walk
397 // carries the raw sum -- so with no increments every year is NonParametric's
398 // curve. No cap; the increments are scored in ceattle.cpp.
399 case SEL_CASE_NP_INTEGRABLE_WALK: {
400 for(int bin = 0; bin < n_sel_bins; bin++){
401 Type inc = (yr > flt_sel_start_yr(flt)) ? sel_coff_dev(flt, sex, bin, yr) : Type(0.0);
402 np_unc(sex, bin, yr) = (yr > 0 ? np_unc(sex, bin, yr - 1) : Type(0.0)) + inc;

404 }

406 for(int bin = 0; bin < n_sel_bins; bin++) base(bin) = non_par_sel(flt, sex, bin, yr);

408 for(int bin = n_sel_bins; bin < nbins; bin++) {
409 non_par_sel(flt, sex, bin, yr) = non_par_sel(flt, sex, n_sel_bins - 1, yr);
410 }
411 { vector<Type> ls(nbins);
412 for(int bin = 0; bin < nbins; bin++) ls(bin) = non_par_sel(flt, sex, bin, yr);
413 avgsel_tmp = log_mean_exp(ls); }
414 for(int bin = 0; bin < nbins; bin++) {

417 non_par_sel(flt, sex, bin, yr) = exp(non_par_sel(flt, sex, bin, yr));
418 if (is_length_based) sel_at_length(flt, sex, bin, yr) = non_par_sel(flt, sex, bin, yr);
419 else sel_at_age(flt, sex, bin, yr) = non_par_sel(flt, sex, bin, yr);
420 }
421 break;
422 }
423
424 case 9: { // NonParametricPM (AMAK "pm"): random walk on the per-year-
425 // renormalized log-selectivity, then a flat bin-cap.
426 // sel_coff = base coefficients (ages 0..n_sel_bins-1, the rest plateauing);
427 // sel_coff_dev = RAW increments at the year they apply. The UNCAPPED centred
428 // curve (np_unc) carries the walk; the realized curve is that held flat above
429 // flt_sel_cap_bin and re-centred (mean(exp) = 1).
430 // At or before the fleet's selectivity start year the curve is built from the
431 // base coefficients alone rather than the running walk -- the AMAK convention
432 // of setting a survey's base selectivity once at its start year.
433 bool from_base = (yr <= flt_sel_start_yr(flt));
434 for(int bin = 0; bin < nbins; bin++){
435 Type prev = from_base ? sel_coff(flt, sex, (bin < n_sel_bins ? bin : n_sel_bins - 1))
436 : np_unc(sex, (bin < n_sel_bins ? bin : n_sel_bins - 1), yr - 1);
437 Type inc = (bin < n_sel_bins) ? sel_coff_dev(flt, sex, bin, yr) : Type(0.0);
438 np_unc(sex, bin, yr) = prev + inc;
439 }
440 for(int bin = n_sel_bins; bin < nbins; bin++) np_unc(sex, bin, yr) = np_unc(sex, n_sel_bins - 1, yr);
441 // Bins below bin_first_selected (e.g. the acoustic-survey age-1) are held at 0
442 // before each year's mean-centring, the AMAK convention for a fixed first-bin
443 // log-selectivity. This keeps the excluded bin out of the shared normalization
444 // of the selected ages and out of the deviate/curvature penalties.
445 for(int bin = 0; bin < bin_first_selected(flt); bin++) np_unc(sex, bin, yr) = 0.0;
446 { vector<Type> u(nbins);
447 for(int bin = 0; bin < nbins; bin++) u(bin) = np_unc(sex, bin, yr);
448 Type m = log_mean_exp(u);
449 for(int bin = 0; bin < nbins; bin++) np_unc(sex, bin, yr) -= m; }
450 { vector<Type> cl(nbins);
451 for(int bin = 0; bin < nbins; bin++) cl(bin) = np_unc(sex, bin, yr);
452 int cap = flt_sel_cap_bin(flt);
